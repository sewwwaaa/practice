Storyline Attack Vector Narrative

An authentic, unified incident investigation pathway:

  1. Perimeter Recon: Recover initial clues embedded in a developer's public image via LSB steganography.
  2. Web API Compromise: Exploit JWT algorithm confusion (`none` algorithm) to breach the staging portal.
  3. C2 Traffic Analysis: Reassemble exfiltrated data split across covert DNS query beacons.
  4. Cryptanalysis: Script a Two-Time Pad attack against flawed AES-CTR keystream reuse.
  5. Binary Deconstruction: Bypass `ptrace` anti-debugging in an ELF implant to discover the port-knock knock sequence.
  6. Privilege Escalation: Hijack a root backup task via Unix wildcard expansion to seize the core bastion flag.
